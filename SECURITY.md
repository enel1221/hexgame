# Security Policy

## Supported versions

Security fixes are applied to the latest release published from a `v*` tag and to the current
`main` branch. Older builds are not supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting flow under the repository's **Security** tab so reports and fixes can be
coordinated without exposing users. Include reproduction steps, affected URLs or versions, and the
impact you observed.

You should receive an initial response within seven days. Confirmed issues will be tracked in a
private security advisory until a fix is ready.
